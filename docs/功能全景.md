## 1. 地图与坐标（产品骨架）
**规则**：照片挂坐标点；isPublic 才对外；天地图瓦片最高 z18。
**实现**：网格聚合标记（$limit 3000）；附近搜索候选上限+距离升序；坐标详情照片墙 takenAt 倒序分页。
**性能（本轮重点）**：弱机实验室（CPUx6+4G 节流）实测定罪——卡顿真凶是请求风暴（16fps），滤镜无罪；处方：预载层 12→2+空闲档、updateWhenIdle+zoomSnap0.5+keepBuffer、放大方向 z+1 中心 3x3 预载；实测 41fps/2.6 倍。
**进行中（未提交）**：v6 MapLibre GL WebGL 引擎切换（王总拍板方案①）——缩放 GPU 无级重采样+瓦片淡入；maplab.html 双引擎对比页（Leaflet/MapLibre 切换+FPS 计）；同款反相滤镜已布到 WebGL 画布。
**成色**：✅ 上线+优化中。

## 2. 会员订阅与半自动支付（收入命脉）
**规则**（方案B）：¥6/30天唯一档；订阅=认证摄影师；不自动续费；到期收回+mode 回落；续费顺延不丢天。
**实现**：pending_confirm+个人收款码+M+6位备注；48h 惰性过期；管理端确认→激活；官方商户号预留状态机。
**成色**：✅ 上线。

## 3. 作品置顶推广（新上线，核心收入增长点）
**规则**（王总 2026-08-31 定稿）：周卡 7 元/7天、月卡 60 元/30天；持卡期间不可叠加再买（续买=顺延）；**排位赛后买靠前**（start 倒序，王总定案 C>B>A）；续买 until=max(now,原until)+时长 且 start 刷新。
**五席循环**：席位档位=月>周>高赞>最新>高赞（ExploreBoost.tier 注释定案）。
**实现**：
- ExploreBoost 集合：coordKey(坐标标题)+authorId+orderId+tier+start+until；唯一索引 (coordKey,authorId) 一作者一坐标一条有效席位；**探索池过滤只读此表，作品/坐标数据永不改动**；
- 下单 POST /explore/boost/order → member.createBoostOrder（**复用会员订单半自动确认链路**）；GET /boost/order/:orderId 供前端 3s 轮询；
- 注入：探索列表按页内坐标批量查活跃 boost（until>now，start 倒序），分 month/week 池挂 boostAuthors 字段；
- 前端 memo-home.html 全套 UI（99 处 boost/置顶相关）。
**待施工（王总已御批「就先这样吧」）**：三层排序架构的免费层公式——新鲜系数（24h×4/3天×3/7天×2/30天×1/更久×0.6）×新人系数（注册≤30天×1.3）+保底（每 6 席插 1 席 24h 内最新）；置顶月卡必须与会员月卡视觉拉开防客诉。参数为暂定，皇上可改。
