# 地图坐标与灵感模式 — 开发对话文档

## 概述

本文档记录了 `memo-home.html` 中地图坐标系统、灵感模式、自由标点、细化程度联动等功能的完整开发过程。

---

## 一、灵感模式坐标聚类

### 需求
- 灵感模式未启动时，自动吸附周围的点，将他人作品汇聚在少的坐标点中
- 只有打开图片时才可以看到作者
- 灵感模式关闭时，保留收藏的坐标点和照片
- 收藏的坐标点距离较近时合并，使照片汇聚在少的坐标点中

### 实现

#### 1. 聚类算法（单链接聚类 Single-Linkage）
- 阈值 `CLUSTER_THRESHOLD = 22`（百分比距离）
- 逐层扩展集群：新点与集群内任意点距离 ≤ 阈值则加入
- 合并后计算质心位置，合并所有照片（去重）

#### 2. 聚类标记视觉
- 径向渐变红色球体 + 白色边框 + 脉冲动画
- 合并数 > 1 时显示金色数量徽章

#### 3. 模式切换行为

| 状态 | 持久坐标显示 |
|------|------------|
| 灵感模式开启 | 展开独立坐标 |
| 灵感模式关闭 | 自动聚类汇聚 |

#### 4. 作者信息隐藏
- 聚类弹窗：隐藏作者名和分隔点
- 照片详情页：点击照片后显示作者，支持跳转个人主页

## 二、他人坐标与普通坐标逻辑统一

### 需求
- 他人上传的红色坐标和自有坐标逻辑相同（聚合/细化/分离密集程度一致）
- 灵感模式下每个他人坐标里的照片可来自不同的人
- 区分照片作者的方式是点击照片后显示，不必在导航键旁边显示作者
- 将灵感坐标生成在其他坐标附近

### 实现

#### 1. 照片级作者数据结构
- 作者信息从坐标级别移到照片级别（`photo.author` / `photo.authorAvatar`）
- 同一坐标内照片可来自不同作者
- 新增坐标：黄龙体育中心（与用户坐标位置重合，便于测试聚类）

#### 2. 弹窗作者始终隐藏
- `showInspirePopup`：作者信息始终 `display: none`
- `showSavedMarkerPopup`：移除作者恢复逻辑
- `showClusteredMarkerPopup`：隐藏作者

#### 3. 照片详情页使用照片级作者
- `openPhotoDetail`：`photo.author` / `photo.authorAvatar` 优先，回退到 `coord.author`
- 个人主页 `openUserProfile`：按照片作者匹配坐标

#### 4. 灵感标记响应细化程度
- `renderInspireMarkers(level)` 接受层级参数
- Level 1：灵感坐标按距离聚类（`clusterInspireForLevel1`）
- Level 2/3：全部独立显示

#### 5. TDZ 修复
- `renderMarkers` 中引用 `inspireMode` 导致 TDZ 错误
- 改用 `document.querySelector('.phone-screen.inspire-mode')` DOM 检测替代变量访问

## 三、自由标点功能

### 需求
- 自由标点后点击屏幕生成新的坐标点
- 颜色为暖色，与当前位置蓝色区分
- 自由标点时细化程度锁定为最细化
- 地图放大到对应缩放大小

### 实现

#### 1. 点击事件绑定
- 从 `amap.on('click')` 改为 `mapContainer.addEventListener('click', ..., true)`（捕获阶段）
- 支持高德地图坐标转换 + 无地图时的 fallback 坐标计算

#### 2. 后备渲染路径
- AMap 不可用时通过 `simMap` 容器渲染标记
- 标记设置 `pointer-events: auto` 确保可点击

#### 3. 新标记颜色
- `#FF7043`（橙红色），区别于当前位置 `#2196F3`（蓝色）

#### 4. 细化程度锁定
- 进入自由标点：`currentDetailLevel = 3`，保存原层级
- 退出自由标点：恢复 `savedDetailLevelBeforeFreeMark`
- CSS 禁用细化程度控件（`pointer-events: none; opacity: 0.35`）

#### 5. 地图缩放同步
- 进入时：`amap.setZoom(LEVEL_TO_ZOOM[3])` → zoom 17
- 退出时：`amap.setZoom(LEVEL_TO_ZOOM[currentDetailLevel])`

## 四、细化程度与地图缩放双向绑定

### 需求
- 细化程度随地图放大而细化，随地图减小而聚合

### 实现

#### 1. 映射关系

| Level | 名称 | Zoom |
|-------|------|------|
| 1 | 低（聚合） | 13 |
| 2 | 中（默认） | 15 |
| 3 | 高（细分） | 17 |

#### 2. 双向同步
- **按钮 → 地图**：`setDetailLevel(level)` 调用 `amap.setZoom()`
- **地图 → 按钮**：`amap.on('zoomend')` 调用 `setDetailLevel(newLevel, false)`
- `syncMap=false` 避免循环触发

#### 3. 自由标点模式保护
- `zoomend` 回调中 `if (freeMarkMode) return`
- 细化按钮中 `if (freeMarkMode) return`
