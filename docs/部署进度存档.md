## 三、卡点与关键决策

1. **ACR 镜像构建的代码源只支持 GitHub 和 Codeup（阿里云云效）——不支持 Gitee**（原方案失误点）
2. **风险待核实**：ACR 绑定 Codeup 可能**不支持个人版/标准版**（来源：developer.aliyun.com/ask/668965 标题"Codeup绑定不支持个人版吗？"）——若确认不支持，需换方案：
   - 备选 1：腾讯云 TCR（个人版免费，需确认是否支持 Gitee/云效代码源）
   - 备选 2：Gitee Go（Gitee 流水线，可构建 Docker 镜像推送到镜像仓库）
   - 备选 3：本地装 Docker 的替代（Rancher Desktop / Podman，国内下载源待验证）
3. **Codeup 个人访问令牌获取**（未完成）：codeup.aliyun.com → 头像 → 个人设置 → 个人访问令牌 → 新建（只显示一次）；克隆账号名在"HTTPS 密码"里
