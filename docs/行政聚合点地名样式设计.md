> 适用范围：`memo-home.html` 地图聚合点（城市/省/国家级）地名标签
> 原则：**只新增类与元素，不改任何现有样式**；现有聚合球体（白边 3px + 径向渐变 + 辉光呼吸动画）外观保持原样
> 状态：已与现有代码核对，可直接交付前端实施

## 1. 地名显示方案 —— 推荐：球体正下方"胶囊小标签"

```
     ●              ●
  ┌─青岛──┐      ┌─青岛·烟台──┐
  4px 间隙    （胶囊标签，pointer-events:none）
```

### 推荐方案：球体下方 4px 处、顶部居中的半透明胶囊标签

| 候选位置 | 评估 | 结论 |
|---|---|---|
| **球体下方小标签（推荐）** | ① 移动端拇指点击目标仍是球体，标签不抢命中区；② 中文 2-4 字在 32px 球内放不下，外部放最清晰；③ 缩放时标签随锚点（iconAnchor 顶部中点）移动不漂移；④ 与高德/Google 地图"地名在点下方"的惯例一致 | ✅ 采用 |
| 球体内部文字 | 32px 内放 2 字中文（字号须 ≤10px）可读性差，且破坏"极简球体"的现有外观 | ❌ 不采用 |
| 球体上方标签 | 国内地图 POI 文字多偏上，容易与相邻 POI 名称叠加；且上方视觉重量与球体辉光冲突 | ❌ 不采用 |
| 点击气泡（popup） | 需多一次点击，行政地名应常显（随缩放出现），不符合"显示地名"需求 | ❌ 不采用 |

### 设计理由
- **可读性**：行政地名是"看地图时快速定位"的信息，常显 > 交互显；胶囊底色保证任何地图底图（深浅、卫星图）下可读。
- **不遮挡**：标签为只读装饰（`pointer-events:none`），地图拖拽、缩放、点击穿透无碍；球体 32px + 标签宽度远小于市面常用聚合点遮挡面积。
- **极简延续**：无数字角标、无边框强调色，标签是"安静的第二层"，视觉层级球体 > 标签。

## 2. 样式规范

### 2.1 标签基础样式（城市级 = 基准）

| 属性 | 值 | 理由 |
|---|---|---|
| 字号 | **12px**（≈24rpx，H5 地图按 px 计） | 中文最小可读字号，<10px 在移动端模糊 |
| 字重 | 600（半粗） | 与标签"名称"语义匹配，不喧宾夺主 |
| 字色 | `#2E3A45`（深灰蓝） | 中性、不抢球体辉光；避免与语义色混淆 |
| 背景 | `rgba(255, 255, 255, 0.92)` 毛玻璃 + `backdrop-filter: blur(6px) saturate(1.2)` | 地图文字透出时仍可读；`-webkit-` 前缀 + 低端机自动降级为 0.92 白底 |
| 圆角 | 10px（全圆角胶囊） | 呼应球体圆形语言 |
| 内边距 | `2px 8px` | 纵向 1 行高度 ≈ 22px，与球体同高节奏 |
| 描边 | `1px solid rgba(255,255,255,0.7)`（内嵌式，`box-shadow: 0 0 0 1px rgba(255,255,255,0.7)`） | 延续"白描边"语言，但只保留 1px 弱化存在感 |
| 投影 | `0 1px 3px rgba(0,0,0,0.18)` | 微浮起、贴地图，不复制球体的强辉光 |
| 间距 | 标签顶部距球体 **4px**（`top: calc(100% + 4px)`） | 留白避免与白边粘连 |
| 交互 | `pointer-events: none`（**必须**） | 关键：标签不拦截地图操作 |
| 动画 | 随聚合点出现：`opacity 0→1` + `translateY(4px→0)`，0.3s ease | 与现有标记入场节奏（0.3s）一致 |

### 2.2 三级行政层级 —— 推荐"球体渐进 + 标签字号渐进"而非换色

| 层级 | data-level | 球体（新增类覆盖尺寸，不动基础类） | 标签字号 | 标签字重 | 语义 |
|---|---|---|---|---|---|
| 城市 | `1` | 32px（沿用现状） | 12px | 600 | 基准 |
| 省 | `2` | **38px**（新增 `.clustered.l2`） | 13px | 600 | 略大 |
| 国家 | `3` | **44px**（新增 `.clustered.l3`） | 14px | 700 | 最大 |

推荐理由：
- **层级用"渐进的球体尺寸"表达**（缩放越远 → 行政层级越高 → 球越大），与用户"放大聚焦"的心智模型一致；同一套标签样式，保证整体统一。
- **不做颜色渐进**：三种模式已有红/紫/主色蓝的语义色，再加层级色会造成"4 套色系 × 3 层级"的组合爆炸；且换色球体需要改动径向渐变的"现有外观"，违反约束。
- 新增 `.clustered.l2/.l3` 只覆盖 `width/height/border-radius/box-shadow 强度`，**径向渐变与呼吸动画从基础类继承，不重写**（辉光强度可随尺寸等比放大，仍属新增覆盖）。
- 标签字号渐进可做可不做，推荐做（低成本、肉眼可辨）。

### 2.3 与现有球体的组合关系（对照）

- 标签永远**不覆盖球体**（在下方），球体点击热区与 hover 放大不受影响。
- 标签 z-index 继承于球体的堆叠上下文（现有 marker z-index 5/6/9），不新增全局 z-index。
- hover 时球体 `scale(1.25~1.3)` 放大——**标签不跟随放大**（标签固定在锚点，避免抖动）。
- 深色地图底图下：白色毛玻璃标签 + 1px 白描边保证可读；不引入深色模式专属变量（保持简单）。

## 3. 边界场景

### 3.1 两个聚合点距离近 → 名称重叠
- **合并逻辑由前端做**（按级别优先级/网格归属），样式侧建议：
  - 合并名称统一用 **"·" 分隔**（如 "青岛·烟台"），视觉上比 "、" 更轻、更像地名拼接而非文本列表。
  - 最多展示 **3 个名称**；超出后省略为 `"青岛·烟台…"`。
  - 标签 `max-width: 140px`，`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`。
  - 省略号由前端控制（拼接时截断 + "…"），CSS 的 ellipsis 只兜底超长。
- 视觉建议：合并标签与单名标签**同一套样式**（不加重、不加宽，靠名称数量传达信息），避免"合并=重要"的误读。

### 3.2 缩放瞬间名称闪烁
- 聚合点合并/解散时 Leaflet 重建 divIcon → 标签随 DOM 重建。建议前端对标签做最小 opacity 过渡（0.15s）避免闪烁；样式已含 0.3s 入场，重建时自然淡入。

### 3.3 相邻两级标签打架（省级标签压到城市球体）
- 前端在合并判定时以**高一级优先**（省 > 城市），样式无额外处理；间距 4px + max-width 已把概率降到最低。

## 4. 实现要点

### 4.1 新增 CSS 类清单（全部为新增，零修改现有规则）

| 类名 | 作用 | 备注 |
|---|---|---|
| `.map-marker .cluster-name` | 地名胶囊标签基础样式（2.1 全量） | 含 `pointer-events:none` |
| `.map-marker.clustered .cluster-name` | 仅聚合点时显示（单标记隐藏） | 复用 `.map-marker` 结构自动生效 |
| `.map-marker.clustered.l2` | 省级球体尺寸 38px（覆盖 width/height/辉光） | 新增，不改基础类 |
| `.map-marker.clustered.l3` | 国家级球体尺寸 44px | 同上 |
| `.map-marker.clustered.l2 .cluster-name` | 省级标签 13px | — |
| `.map-marker.clustered.l3 .cluster-name` | 国家级标签 14px/700 | — |
| `.map-marker .cluster-name.merge`（可选） | 合并名称标签（若需与单名区分时用） | 默认推荐不加，保持统一 |

命名规则：`cluster-name` 表意清晰、与 `clustered` 语义联动、不与现有类冲突（全文件无同名）。

### 4.2 DOM 结构建议

现有（L3991 等，三处创建点 3991 / 5864 / 6118 / 6778 同样改造）：
```html
<div class="map-marker clustered" style="background:...;pointer-events:auto;"></div>
```

改为（注意：`L.divIcon` 的 `iconSize` 仍按球体 32px 计算，锚点不变，标签用绝对定位溢出绘制，Leaflet 不裁剪）：
```html
<div class="map-marker clustered l2" data-level="2" style="background:...;pointer-events:auto;">
  <span class="cluster-name">山东</span>
</div>
```

关键点：
- **标签定位在子元素上**：`position:absolute; top:calc(100% + 4px); left:50%; transform:translateX(-50%)`。子元素内部的 translate 不影响高德 Marker 的 offset（L138 冲突只针对 `.clustered` 自身，已核对无风险）。
- `data-level` / `l2/l3` 类由前端聚合逻辑赋值；无行政名时不渲染 `.cluster-name` 子元素（保持现有纯球体）。
- 由于 `iconSize` 锚点仍为球体中心，标签溢出部分可能被相邻 POI 覆盖——已用 `pointer-events:none` + 1px 白边 + 0.92 白底保证可读。

### 4.3 避免遮挡地图操作（检查项）
1. `.cluster-name { pointer-events: none; }` —— 唯一拦截的是球体（沿用现有 inline `pointer-events:auto`）。
2. 标签不新增 z-index，跟随球体堆叠。
3. 标签 hover 不放大、无独立 hover 态（减少误触与抖动）。
4. `backdrop-filter` 加 `-webkit-` 前缀；不支持时 `rgba(255,255,255,0.92)` 兜底（本身已近不透明，无功能损失）。
5. 标签文字用 `font-family` 继承现有页面字体栈，不新增字体加载。

## 5. 验收标准（视觉一致性检查清单）

对照现有标记（L99/L1836/L1905 三处基准）逐项验收：

| # | 检查项 | 判定标准 | 对照现有 |
|---|---|---|---|
| 1 | 白描边语言 | 标签描边为 1px 白（内嵌式），球体仍 3px 白边，视觉上"同族不同级" | `.map-marker` border 3px white |
| 2 | 圆形语言 | 标签圆角 10px 胶囊、球体 50% 圆形，无方形元素出现 | `border-radius: 50%` |
| 3 | 辉光克制 | 标签只有 0.18 微投影，无呼吸辉光；辉光仅属于球体 | `clusterPulse 1.8s` |
| 4 | 动画节奏 | 标签入场 0.3s ease 与标记/球体 0.3s 一致，无新节奏 | `transition 0.3s ease` |
| 5 | hover 行为 | 球体 hover 放大（1.25/1.3），标签保持原位不放大、不抖动 | L110/L1848/L1903 |
| 6 | 无数字回潮 | 标签内只有地名，绝不显示数量数字（保持极简承诺） | 徽章已移除 |
| 7 | 层级可辨 | 缩放越远球体越大（32→38→44），文字 12→13→14px，肉眼可辨 | 新增能力 |
| 8 | 可读性 | 深浅地图底图（含卫星图）下文字对比度 ≥ 4.5:1（#2E3A45 对 0.92 白） | 无现成参照 |
| 9 | 零回归 | 运行 `git diff` 或人工比对：现有 `.map-marker` / `.clustered` 规则零修改；无 `.clustered` 自身 translate | L138 约束 |
| 10 | 三模式一致 | saved（红）、explore（紫）、主地图（inline 色）三处均出现同名 `.cluster-name` 且样式一致 | L3991/5864/6118/6778 |

**通过条件**：#9 必须为零修改，其余 9 项全部通过视为达标。
