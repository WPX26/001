# 安卓屏控 · HBuilderX 云打包与真机验证（2026-08-20）

> 屏控网页端已上线后，**A 机还需安装含屏控插件的新 APK**（本机无 Gradle，走 HBuilderX 云打包，无需装 Android Studio）。

## 1. 云打包步骤（约 10 分钟，王总操作）

1. **装 HBuilderX**：官网 https://www.dcloud.io/hbuilderx.html 下载 App 开发版（需 3.99+ 以支持 Android 14 录屏前台服务），用 **DCloud 账号**登录（注册免费）。
2. **打开项目**：HBuilderX → 文件 → 导入 → 从本地目录导入 → 选择
   ```
   C:\Users\lenovo\地图相册111\uni-preset-vue-vite
   ```
   首次打开会自动安装依赖（或提示运行 npm install，已在仓库 node_modules，一般直接可用）。
3. **确认 AppID**：双击 `src/manifest.json` → 「基础配置」→ 若 AppID 为空点「重新获取」用 DCloud 账号一键创建。
4. **（可选）检查权限**：UTS 插件自带的 AndroidManifest.xml 会自动合并（前台服务 / 无障碍 / 通知权限），无需手动勾选。
5. **云打包**：菜单 **发行 → 原生App-云打包**：
   - 平台勾选 **Android（apk）**
   - 证书：选「**使用云端证书（公共测试证书）**」即可（正式上架再换自有证书）
   - 点「打包」→ 等云端编译（几分钟，页面显示进度）
6. **下载安装**：打包完成后点「下载」→ 传到 A 机（微信/数据线）→ 安装（需允许「安装未知来源应用」）。

> 若云打包报 UTS 编译错误，把完整报错发我，我来修插件代码（本机无法编译 UTS，只能靠云打包反馈）。

## 2. 真机验证清单（两机）

**A 机（Android，装新 APK）**：
1. 打开 App → 底部「联机」页 → 手机互联 → 开始连接手机 → 看到 6 位连接码
2. 点 **「屏幕共享」**：
   - 首次弹「**开始录制或投射**」→ 选「立即开始」→ 允许（可勾选「不再询问」）
   - 首次会弹窗「需先开启无障碍」→ 点「去开启」→ 系统设置 → 无障碍 → 已安装的服务 → **地图相册** → 开启 → 返回
   - 按钮变为「停止共享」，状态行显示「屏幕共享中 · 控制端可远程操作」

**B 机（任意手机/电脑浏览器，无需装 App）**：
3. 打开 https://dsofatjxxjyf.sealoshzh.site/connect-prototype.html → 手机互联 → 输入 A 屏上的 6 位码
4. 看到 A 机全屏画面 → 提示变为「已接管屏幕 · 点击/滑动即可远程操作被控手机」
5. 测试：
   - **点** A 屏上的图标/按钮（如打开系统相机）
   - **滑** 桌面翻页、相册滑动
   - **长按** 图标出现菜单
   - 底部「返回 / 主页」键
   - 打开系统相机后 **点快门** → A 机拍照 → B 端相册角标 +1

## 3. 常见问题
| 现象 | 处理 |
|------|------|
| B 看不到画面 | A 端是否点「屏幕共享」且授权成功；A/B 是否同一连接码 |
| 看得到画面但 B 点不动 | A 端无障碍服务没开 → 回第 2 步开启；部分 ROM（MIUI/EMUI）还需「应用管理→地图相册→允许后台弹出」 |
| 画面卡顿 | 帧率约 5fps 属预期；WiFi 下最佳 |
| 系统相机黑屏 | Android 14 个别机型对系统相机有 secure 保护 → 改开我们 App 相机页（全屏取景） |
| 点了「屏幕共享」没反应 | App 是否为最新云打包包；是否已授权录屏 |
