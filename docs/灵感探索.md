## 1. 一句话结论

memo-home.html 的灵感/探索演示数据已改为**真实后端优先**：
登录态下调用 `GET /inspire/coords` 与 `GET /explore/coords`（页面内直接 fetch，
不动 api.js，避免与并行会话冲突）；接口不可达 / 未登录 / 业务失败 → **自动降级原演示数据**；
后端返回空列表 → **空态提示**。视觉样式 / 布局 / 交互未改（演示数据路径行为与改动前完全一致）。

## 2. 方案摘要

- 原 `const inspireData / exploreData` 写死字面量 → 改名 `inspireFallbackData / exploreFallbackData`
  作为**离线降级数据**；新增 `let inspireData / exploreData` 可被真实数据整体替换。
- 新增 `loadInspireExploreFromBackend()`：登录后并发拉取两个接口，成功后用适配函数
  把后端字段映射为前端渲染结构并整体替换数据源；任一失败 → console 提示并保持演示数据。
- 真实坐标标记 `_remote: true`：演示专用的「坐标对齐到五四广场」逻辑跳过真实坐标，
  真实坐标按后端 lng/lat 原样落图；聚类时对无 x/y 的真实坐标按当前视口**屏幕像素**补算，
  复用原有单链接聚合（行为与演示一致）。
- 照片卡片 / 照片详情：真实照片有 imageUrl/thumbnailUrl 时以真实图片展示（cover），
  无图（演示数据）保持原渐变块。
- 作者名 → 后端用户 id 自动登记（MemoAPI.setUserBackendId），他人主页真实化 / 关注同步沿用现有机制。

## 4. 降级与空态

- **未登录 / 接口不可达 / 业务错误（code≠0）**：`inspireDataIsRemote / exploreDataIsRemote` 保持 false，
  数据源维持演示数据，交互与改动前完全一致（console 提示、不弹 UI）。
- **后端返回空列表**：数据源替换为空数组、remote 标记置 true；进入灵感/探索模式时
  以现有 showToast 提示「💡 附近暂无灵感坐标 / 📡 附近暂无探索作品」（空态），不渲染任何标记。

## 7. 遗留事项 / 说明

- 灵感/探索数据仅在**页面加载时**拉取一次（中心点 = 当前地图中心，半径 ≥5km 覆盖视口）；
  未实现拖拽/缩放后自动重新拉取（现有演示数据也是静态的，交互保持一致）。
- 真实照片若后端无缩略图/大图（仅色块兜底），展示行为与演示一致。
- /explore 后端无 per-coord 照片归属，采用「作者分组照片挂到该作者各坐标」映射；
  同一作者多个坐标弹窗照片相同（后端接口契约决定，后续接口升级可细化）。
- 后端打赏数（tips）不在 /inspire、/explore 返回中，前端置 0；打赏动作仍走真实接口并以后端返回回填。
- 本改动未 git add/commit/push、未部署（按铁律）。
