# ftp-receiver 示例页接入说明

## 运行步骤

1. 在 `src/pages.json` 的 `pages` 数组中加入：

   ```json
   { "path": "uni_modules/ftp-receiver/example/pages/ftp-server-demo" }
   ```

2. 使用 HBuilderX **自定义基座**运行到 Android 真机（示例涉及前台服务与原生 socket，标准基座不含本插件原生代码）。

3. 真机流程：
   - 打开手机热点（相机需连入同一热点）；
   - 点击「启动服务」，页面展示 IP/端口/随机账号（每次启动随机生成，D6）；
   - 相机 FTP 设置：服务器 = 页面 IP（典型 192.168.43.1），端口 21，账号密码 = 页面展示值；
   - 佳能相机：如教程要求关闭被动模式（PORT 模式），请按相机关闭"被动模式"选项测试；
   - 拍摄并上传后，页面「文件接收」与「事件日志」实时更新。

## 示例页职责边界

示例页仅演示插件 API 生命周期与事件流，**不属于主产品 UI**。主产品接入时：

- 账号随机生成、连接引导页文案、通知文案等均需按产品设计实现；
- 文件到达后的业务管线（EXIF/GPS → 500m 归类 → 本地库）由业务层实现，见插件根 `readme.md`「与 H5 原型的对接点」。

## 已知注意

- Android 13+ 首次启动会申请通知权限（L2）；拒绝后服务仍可运行，但常驻通知不可见。
- 服务需前台运行上下文启动（页面在前台时点击启动）；后台冷启动前台服务会被系统限制（ForegroundServiceStartNotAllowedException）。
